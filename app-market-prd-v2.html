CONSUMER UX RULES

以最短成功路径为核心

✓首屏先展示输入与效果，不让用户理解 Skill/Agent/MCP
✓一步一件事：拍照、语音、脚本可并行补足
✓根据字段类型选控件；必要时由对话补齐不完整信息
✓费用与试用条件必须在执行前可见
✓成果、历史、编辑、下载及失败返还同一路径闭环
✓移动端摄像头、麦克风授权可理解、可取消
OPERATOR UX RULES

默认隐藏检查过程

✓自动解析 Skill 完整依赖与顺序，而非只测试一条 Happy Path
✓从 Schema / 样例生成互动卡片与正反向测试
✓平台差异明确：Skill UI、Connection、权限、Runtime、媒体 Worker
✓失败结果附最短修复入口，而非展示技术日志墙
✓自动记录输入、输出、Runtime 身份、调用与成本证据
✓达标才允许灰度、上架、回滚；版本不可静默覆盖

ARCHITECTURE AUTHORITY

不能走偏的边界

仍以 Astra Employee / Conversation / Work Journal / Artifact / Permission / Connection / Ontology 为核心；Skill 是业务能力，Tool 提供通用操作，UI 是动态投影，Runtime/Browser/Office 为可替换 Port。不得再建消费者专用第二套 Agent Registry、Task/Run/Workflow Core，也不为每个应用硬编码 HTML 表单或新容器。

视频等媒体应用需要独立验证媒体供应链、任务时长、可用区与授权（照片、音色与人物肖像）。不得拿一个本地 Hermes 文本输出成功冒充视频可交付。
