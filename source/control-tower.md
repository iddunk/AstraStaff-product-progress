## C 目标产品架构 {span=2}
```flow TB
用户 -> *Employee: 自然语言交办
*Employee -> Responsibility: 长期职责
*Employee -> Work: 本次工作
Responsibility -> Work: 定时 / 事件 / 轮询 / 手动触发
Work -> Policy / Approval: 权限与例外判断
Work -> Agent Runtime: 自由执行
Agent Runtime -> Skills / Tools: 业务能力
Skills / Tools -> Thin Waist Ports: 调用边界
Thin Waist Ports -> 企业系统: 美团 / 抖音 / 钉钉 / Office
Work -> *Outcome: 可验证业务结果
*Outcome -> Artifact: 文件 / 预览 / 附件
*Employee -> Context / Memory: 企业事实与长期偏好
*Employee -> Connection: 登录身份与授权资源
```

**关键边界：** Runtime、Browser、Office、模型和 Temporal 都可替换。Employee、职责、权限、记忆与结果不能跟着 Provider 漂移。
